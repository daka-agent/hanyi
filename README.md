## 一句话

> **借洋节的鬼，讲中国的鬼。**

十月三十一日只是发布档期，不是节日主题。全作零西方万圣节符号，讲的是中国三大鬼节之一「寒衣节」（农历十月初一）：给亡人送寒衣的日子。

## 关于「鬼」

这一作的鬼**不是可怕的，也不是温暖的**，是第三种：**还没把事办完的人。**

- 行为是诡异的（无脸、退着走、没有脚跟）
- 动机是温柔的（喊冷、缝了很久、怕你冷）
- 距离是始终不变的（她不出现形象、不拥抱、不流泪、不解释身世）

真正的恐怖来源不是鬼，是**时间**：她等了一整个秋天，而距十月朔只剩九天。

## 考据

游戏中 8 条引文均注出处，虚构设定单独标注。所述为文献记载的岁时民俗，**非信仰主张**。

主要依据：

- 明·刘侗、于奕正《帝京景物略》：「十月一日，纸肆裁纸五色，作男女衣，长尺有咫，曰寒衣。有疏印缄，识其姓字辈行，如寄书然。」
- 汉·王充《论衡·订鬼》引《山海经》：门户画神荼、郁垒与虎，悬苇索以御凶魅
- 晋·葛洪《抱朴子·登涉》：老魅「其去必却行」，转镜照其后方见「无踵」
- 清·纪昀《阅微草堂笔记》：「鬼，人之余气也」，气以渐而消，消已尽也
- 宋·孟元老《东京梦华录》：九月下旬即卖冥衣，「以十月朔日烧献故也」

十月初一其实有两条线：**送寒衣（给亡人）**与**授衣（给活人添冬衣）**。所以最后那件寒衣，不是编的桥段——它本来就是这个节日的另一半。
